## 実行手順

1. 元の .skp を別名で保存し、バックアップを残す
2. `tomita_fix_20261005.rb` をダウンロードする（`C:/Users/zhang/Downloads` に保存される前提）
3. SketchUp で .skp を開き、[拡張機能] → [Ruby コンソール] で次の1行を貼り付けて Enter
   ```ruby
   f = Dir.glob('C:/Users/zhang/Downloads/tomita_fix*').max_by { |x| File.mtime(x) }; puts f; load f
   ```
   - 同じ名前のファイルが「(1)」「(2)」付きで増えても、いちばん新しく保存されたものを読み込みます。
   - 1行目にファイル名、2行目に「TomitaFix 2026-10-06 v8.1（…）を読み込みました」と出れば正しいファイルです。
4. STEP A → C → D → E → F → G → H → I → J → B の順に自動で実行されます。ログは Ruby コンソールに出ます。
   - 実行済みの STEP A・C は自動でスキップされます。
     前回のスクリプトを実行済みのモデルに新しいスクリプトを読み込むと、STEP D と B だけが実行されます。
   - STEP D・G・H・I・B は何度実行しても問題ありません。
   - STEP J（外構）は1回だけ実行されます。
   - 妻面の壁を土壁にする処理（STEP D）は、一度土壁にしたモデルでは何もしません（手でガラスに変えた面を戻さない）。
   - STEP E のうち、鉄骨化と軒の変更は1回だけ実行されます。STEP F も1回だけです。
     天井の板・家具・手摺の色は、実行のたびに作り直されます。
   - 元に戻すときは [編集] → [元に戻す] を、実行された STEP の数だけ押します。

座標系: モデル原点は「通り芯 X0/Y0・1FL±0」で、X が東、Y が北です（単位 mm）。
寸法は、モデル内 DWG の柱芯をモデルの柱芯に重ねて読み取りました。全通り芯でずれは 0mm でした。
DWG では線種（実線／破線）が失われているため、壁かどうかは PDF の線種で判断しました。
実線は壁、破線は「壁なし（領域の区切り）」として扱っています。

## STEP B: 階別タグ

タグフォルダ「階別」の中に `1F` / `2F` / `3F` / `RF_屋根` / `複数階_通し部材` を作ります。

- 既存の部位別タグは親グループに残すので、部位別・階別のどちらでも表示を切り替えられます。
- 階は要素の下端の高さで判定します。各階の判定開始は FL−900 です（床スラブ・床梁は上の階に入ります）。
- 名前が「1F／2F／3F」で始まるグループと「風除室」は、FL 直下にある要素をその名前の階に入れます。
- 2F デッキと 3F 展望テラスのように、1つのグループの中で面ごとに階が違うものは、面ごとに振り分けます。
