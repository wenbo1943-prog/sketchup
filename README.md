## STEP B: 階別タグ

タグフォルダ「階別」の中に `1F` / `2F` / `3F` / `RF_屋根` / `複数階_通し部材` を作ります。

- 既存の部位別タグ（01_構造_柱梁床 など）は親グループに残り、階別タグはその中の要素に付きます。
  このため、部位別・階別のどちらでも表示を切り替えられます。
- 階の判定はワールド座標での要素の下端の高さで行います。各階の判定開始は FL−900 です
  （1F: 〜4,100 / 2F: 4,100〜 / 3F: 8,600〜 / RF: 13,100〜）。これで床スラブと床梁は上の階に入り、1F天井（4,000）は1Fに入ります。
- 上端が次の階の判定開始＋2,500 を超える要素（通し柱 0〜14,000 など）は `複数階_通し部材` になります。
- 名前が「1F 」「2F 」「3F 」で始まるグループと「風除室」は、FL 直下の要素をその名前の階に入れます。
  例: 1F下屋の東側の瓦（4,820〜5,200）→ 1F。
- 外構グループと、モデル直下にある参考 DWG・添景人物は変更しません。
